# The fixed numbers of the code

Every top-level numeric constant in `src/engine`, `src/node`, `src/main` and `src/chronicler`, and where it belongs (M10.20). Generated by `npm run knobs` from the code and `docs/knobs.yaml`; do not edit by hand. A test fails when the code has a number that `docs/knobs.yaml` does not place.

89 rules of play are knobs of a world, and 13 ways the app behaves are knobs of the app. Still in the code: 150 numbers, of which 8 are for the content of a world, 7 for the settings of the app, 84 stay in the code, and 51 are units of time; 11 of them are only the default of something that has moved.

## The knobs of a world (89)

A world sets any of these in `world.yaml` under `knobs:`, by id: one number, or for a table only the rows that differ.
